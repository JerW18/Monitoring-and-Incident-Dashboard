# Candidate Work Submission

Use AI tools to design and build a working project of your choice. The purpose is to demonstrate how efficiently and effectively you use AI to deliver a working result. Your submission will help us decide whether to invite you to an on-site interview.

## Project Requirements

- **Languages:** Rust, Node.js (JavaScript or TypeScript), Go, or Python.
- **Environment:** Target to Linux, Docker, or a cloud environment.
- **Submission:** A GitHub or other Git repository accessible to reviewers.

## What to Include

- A working project with a brief introduction and instructions to run it.
- A short account of your AI-assisted workflow: tools used, key steps, approximate time spent, and how you checked the result.
- Design / Architecture diagrams or demonstration.

## Review Criteria

We focus on how effectively you direct AI, evaluate its output, and use it to reach a working result efficiently. Keep the scope manageable; project size and documentation volume are not priorities. Be prepared to explain your approach and the result.
